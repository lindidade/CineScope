# 🎬 CineScope — Modern Movie Discovery Platform

A full-stack web application for movie discovery, built with ASP.NET Core MVC.

🚀 Features

- Browse and search movies by title and genre
- Movie cards with posters, ratings and details
- User authentication with role-based authorization
- Write and read movie reviews
- Import movies automatically from TMDB API
- Admin dashboard with analytics
- Dark theme with custom color palette

🛠️ Tech Stack

- **Backend:** ASP.NET Core MVC 10
- **Database:** SQL Server + Entity Framework Core (Local Server)
- **Authentication:** ASP.NET Identity
- **Frontend:** Razor Views + Bootstrap 5 + Custom CSS
- **API:** TMDB (The Movie Database)

👥 User Roles

| Role | Permissions |
|------|-------------|
| Guest | Browse movies, search, view details |
| Member | Guest + write reviews and ratings |
| Admin | Member + full CRUD, manage reviews, dashboard |

⚙️ Getting Started

Prerequisites
- Visual Studio 2022
- SQL Server / LocalDB
- .NET 10 SDK
